# idric-graphql

Typed GraphQL work for Idriç.

Reference implementations are kept under `_reference.code/`; production source must not depend on them.

## Reference corpus

- `_reference.code/CATALOG.md` — inventory of strongly typed functional GraphQL libraries found in this research pass, including negative searches for Idris, Agda, Lean, Coq, and F*.
- `_reference.code/SOURCES.tsv` — exact upstream revisions, licenses, local paths, and whether each copy is complete source, an architectural slice, or an explicit excerpt.
- `_reference.code/README.md` — rules for using the reference corpus without turning it into a production dependency.
